КТ 3. REST API блога
Express, Prisma ORM и SQLite. CRUD пользователей и постов, теги, фильтрация, пагинация и валидация через Joi.
Запуск
Нужен Node.js 22.12 или новее. В корне проекта:
npm install
npm run setup
npm start
Адрес API: http://localhost:3000. Настройка .env и базы выполняется автоматически через npm run setup.
Проверка
npm test
Для ручной проверки: коллекция kt03.postman_collection.json в Postman.
